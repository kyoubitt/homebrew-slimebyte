# homebrew-slimebyte

Homebrew tap for [SlimeByte](https://github.com/kyoubitt/SlimeByte), the Minecraft slime farm finder.

```sh
brew install kyoubitt/slimebyte/slimebyte
slimebyte
```

macOS has no CUDA, so the Best AFK / Cluster search runs on the Mac's graphics card through OpenCL, or
on the CPU if that doesn't work (`slimebyte doctor` says which).

SlimeByte is based on [xvyz1/Vibecoded-Slime-Chunk-Finder](https://github.com/xvyz1/Vibecoded-Slime-Chunk-Finder).
