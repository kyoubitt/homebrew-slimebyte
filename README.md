# homebrew-slimebyte

Homebrew tap for [SlimeByte](https://github.com/kyoubitt/SlimeByte), the Minecraft slime farm finder.

```sh
brew install kyoubitt/slimebyte/slimebyte
slimebyte
```

macOS has no CUDA, so this install does Manual scoring, the map and the perimeter commands; the GPU
search (Best AFK / Cluster) needs an NVIDIA GPU on Linux or Windows.
